# 🐱 貓咪領地拼圖 (Queens: Cat Edition)

**[👉 點此立即遊玩 (Play Now) 👈](https://pondahai.github.io/queens-cat-edition/)**

這是一款類似 LinkedIn "Queens" 或 "Star Battle" 的硬核純邏輯解謎遊戲。在柔和的粉彩方格中，玩家必須利用精確的邏輯推導，在 N x N 的網格中為每一隻貓咪找到唯一的專屬領地。

本遊戲保證**100% 動態隨機生成**且**嚴格具有唯一解**，不靠運氣，純靠腦力！

---

## 🎮 遊戲玩法與核心規則

在盤面中放置 N 隻貓咪，必須**同時滿足**以下三大鐵律：

1. **區域唯一 (Region)**：盤面被劃分為 N 個不同顏色的色塊，每個色塊內部 **恰好只能放置一隻貓**。
2. **行列排他 (Row & Column)**：每一橫列、每一直欄，**恰好只能放置一隻貓**。
3. **社交安全距離 (8-Way No-Touch)**：任意兩隻貓之間絕對不能相鄰，包含上下、左右，以及**4 個對角線（斜角）**都不能有其他貓咪。

### 💡 操控方式
* **左鍵點擊**：在「空白」 ➔ 「打叉 (✕)」 ➔ 「放貓 (🐱)」之間循環切換。
* **右鍵點擊**：快速標記或取消打叉 (✕)。
* **滑動標記**：按住滑鼠或在觸控螢幕上滑動，可連續畫出 (✕) 排除不可能的區域。
* **智慧提示**：卡關時點擊燈泡，系統會依據唯一解，幫你在正確的格子上標記一隻貓咪。

## 🛠️ 開發與製作過程 (The Making-of)

這款遊戲看似簡單，但在「純前端動態生成」的架構下，經歷了數次演算法的砍掉重練。最大的挑戰在於：**如何隨機生成有機的色塊形狀，同時在數學上保證地圖有且僅有「唯一解」？**

### Phase 1：隨機擴展的盲點 (The Voronoi Trap)
最初的演算法採用隨機找 N 個不衝突的點當作種子，接著用 Flood-Fill 向外擴展生成色塊。
* **遇到的 Bug**：隨機生長的色塊經常在盤面邊緣形成死胡同，或者造成某個色塊被迫要容納 2 隻貓才能滿足行列條件。這導致系統產出了大量「無解」或「多解」的死局。

### Phase 2：導入回溯驗證器 (CSP Backtracking Solver)
為了解決死局，遊戲核心植入了一個嚴謹的**約束滿足問題 (Constraint Satisfaction Problem) 求解器**。
* **進化**：每次隨機生成色塊後，系統會在背景使用位元遮罩 (Bitmask) 與最小剩餘變數 (MRV) 演算法，對整張地圖進行全域求解。如果 `countSolutions() !== 1`，系統會毫不留情地將其丟棄重算。

### Phase 3：解除平滑限制，擁抱 1x1 孤島 (The Breakthrough)
在套用嚴格回溯求解後，遇到了一個效能瓶頸：為了讓地圖「好看」，原本限制了色塊不能太小。這導致演算法極難在茫茫解海中隨機撞中「唯一解」，造成生成器卡頓。
* **最終解答**：我們移除了色塊大小的限制，**允許 1x1 或 1x2 這種「畸形」極小色塊的存在**。
* 在邏輯解謎中，1x1 的色塊是玩家最關鍵的突破口！它能讓玩家有確定的起手式，進而引發強烈的邏輯連鎖反應（骨牌效應）。這個改變不僅讓生成器速度飆升，也讓題目的推導過程變得極具層次與挑戰性。

## 💻 技術堆疊 (Tech Stack)

* **核心**：純 Vanilla JavaScript (ES6+)
* **演算法**：DFS/BFS 幾何生長、Backtracking (回溯法)、位元運算剪枝
* **樣式**：Tailwind CSS (透過 CDN 即時編譯) 搭配自訂 CSS 動畫
* **音效**：Web Audio API 原生合成音效（無須外部聲音檔）
